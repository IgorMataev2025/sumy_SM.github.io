**Дата:** 2026-09-01

**Репозиторій:** https://github.com/IgorMataev2025/sumy_SM.github.io

## 1. Мета проєкту

Створити веб-портал для мешканців міста та Сумської області, на якому фізичні та
юридичні особи (постачальники послуг) можуть розміщувати інформацію про свої
послуги, а мешканці (отримувачі послуг) — знаходити та користуватись цією
інформацією.

## 2. Ролі користувачів

| Роль | Опис | Доступ |
|---|---|---|
| **Гість** | Неавторизований відвідувач | Лише сторінка входу/реєстрації, публічна інформація про портал |
| **Споживач** | Зареєстрований мешканець, шукає послуги | Перегляд/пошук/фільтрація оголошень (після реєстрації) |
| **Постачальник** | Фіз. або юр. особа, надає послуги | Створення, редагування, видалення власних оголошень; перегляд статусу модерації |
| **Адміністратор** | Власник порталу (Ігор Матаєв) | Модерація оголошень, керування категоріями, керування користувачами |

> Рішення: перегляд оголошень також вимагає реєстрації/авторизації
> (закритий портал, не публічний).

## 3. Категорії послуг (MVP)

1. Побутові послуги (ремонт, клінінг, сантехніка, електрика тощо)
2. Медицина та здоров'я (приватні лікарі, клініки, стоматологія)
3. Освіта та репетиторство (курси, репетитори, дитячі гуртки)
4. Комунальні / державні послуги (інформація від ОСББ, комунальних служб, адмінпослуги)

Категорії зберігаються в БД (таблиця `Categories`) — розширювані без зміни коду.

## 4. Функціональні вимоги (MVP)

### 4.1 Реєстрація та авторизація
- Реєстрація за email + паролем (підтвердження email)
- Вибір типу акаунта при реєстрації: **Споживач** / **Постачальник**
- Для постачальника — вибір: фізична особа / юридична особа
  (юр. особа: назва компанії, ЄДРПОУ, контактна особа)
- Хешування паролів (не зберігати у відкритому вигляді)
- Відновлення пароля через email

### 4.2 Оголошення послуг (постачальник)
- Створення оголошення: категорія, назва, опис, ціна/діапазон цін,
  контактні дані, адреса/район, фото (до N штук)
- Статуси оголошення: `Чернетка → На модерації → Опубліковано / Відхилено`
- Особистий кабінет: список власних оголошень зі статусами, редагування, зняття з публікації

### 4.3 Модерація (адміністратор)
- Черга оголошень «на модерації»
- Схвалення / відхилення з коментарем (причина відхилення видима постачальнику)
- Керування категоріями (додати/редагувати/деактивувати)
- Керування користувачами (блокування недобросовісних акаунтів)

### 4.4 Перегляд і пошук (споживач)
- Каталог оголошень з фільтрами: категорія, район, ключове слово, ціна
- Картка оголошення: повний опис, фото, контакти постачальника
- Пагінація списків

## 5. Технологічний стек

| Компонент | Рішення |
|---|---|
| Мова / фреймворк веб-частини | **VB.NET, ASP.NET Web Forms, .NET Framework 4.8** |
| СУБД | **MySQL** (доступ через MySQL Connector/NET, `MySql.Data.MySqlClient`) |
| Веб-сервер | IIS (Windows-хостинг) |
| Контроль версій | Git / GitHub (`sumy_SM.github.io`) |
| Хостинг живого порталу | Окремий Windows-хостинг з підтримкою ASP.NET + MySQL (напр. SmarterASP.NET або аналог) — **GitHub Pages не підтримує серверний код** |

## 6. Архітектура розгортання

- **GitHub-репозиторій** (`sumy_SM.github.io`) — сховище вихідного коду проєкту
  (control version). GitHub Pages з нього роздає лише статичну
  **landing-сторінку проєкту** (`index.html`) — опис порталу, статус розробки,
  контакти. Це НЕ сам портал.
- **Реальний портал** (авторизація, оголошення, БД) розгортається на окремому
  Windows-хостингу з IIS та MySQL, під окремим доменом.
- Адміністрування хостингу, домену та юридичних реквізитів — самостійно,
  Ігор Матаєв як фізична особа.

## 7. Попередня структура БД (MySQL)

```
Users
  UserId          INT PK AUTO_INCREMENT
  Email           VARCHAR(255) UNIQUE
  PasswordHash    VARCHAR(255)
  FullName        VARCHAR(255)
  Phone           VARCHAR(50)
  UserType        ENUM('Consumer','Provider')
  IsLegalEntity   BOOLEAN DEFAULT FALSE
  CompanyName     VARCHAR(255) NULL
  EDRPOU          VARCHAR(20) NULL
  District        VARCHAR(100) NULL
  IsActive        BOOLEAN DEFAULT TRUE
  CreatedAt       DATETIME

Categories
  CategoryId      INT PK AUTO_INCREMENT
  Name            VARCHAR(150)
  Description     VARCHAR(500) NULL (короткий підпис картки категорії)
  ParentId        INT NULL (FK Categories, для підкатегорій)
  IsActive        BOOLEAN DEFAULT TRUE

Services
  ServiceId       INT PK AUTO_INCREMENT
  ProviderId      INT FK -> Users
  CategoryId      INT FK -> Categories
  Title           VARCHAR(255)
  Description     TEXT
  Price           DECIMAL(10,2) NULL
  District        VARCHAR(100)
  Phone           VARCHAR(50)
  Status          ENUM('Draft','Pending','Approved','Rejected')
  RejectReason    VARCHAR(500) NULL
  CreatedAt       DATETIME
  ApprovedAt      DATETIME NULL
  ApprovedBy      INT FK -> Users NULL

ServicePhotos
  PhotoId         INT PK AUTO_INCREMENT
  ServiceId       INT FK -> Services
  FilePath        VARCHAR(500)

ModerationLog
  LogId           INT PK AUTO_INCREMENT
  ServiceId       INT FK -> Services
  AdminId         INT FK -> Users
  Action          ENUM('Approved','Rejected')
  Comment         VARCHAR(500)
  ActionDate      DATETIME
```

## 8. Нефункціональні вимоги

- Захист від SQL-ін'єкцій — лише параметризовані запити
- HTTPS на живому хостингу
- CAPTCHA на формі реєстрації (захист від ботів)
- Адаптивна верстка (mobile-friendly)
- Інтерфейс українською мовою

## 9. Етапи розробки

1. **Інфраструктура** — вибір/реєстрація хостингу з ASP.NET+MySQL, домену,
   базовий каркас Web Forms проєкту, підключення до БД
2. **Авторизація** — реєстрація, вхід, ролі, відновлення пароля
3. **Оголошення** — CRUD для постачальника, завантаження фото
4. **Модерація** — адмін-панель, черга схвалення
5. **Каталог і пошук** — перегляд, фільтри, пагінація для споживача
6. **Тестування та публікація** — деплой на бойовий хостинг
